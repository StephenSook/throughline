Every number below is computed from live public APIs during a reconciliation run. Nothing here is hardcoded, and any figure can be walked back to its source record.

What this is not. Throughline is not a case management system, does not score risk, and makes no automated decision about any person. It surfaces discrepancies between authorities. Humans decide, always.
